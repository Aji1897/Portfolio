# React Portfolio

Portfolio starter built with React and Vite.

## Folder Structure

```text
src/
  assets/
    images/        Static images used by the portfolio
    logos/         Optional logos or brand marks
  components/      Reusable UI pieces
  data/            Portfolio content, links, skills, and projects
  sections/        Main page sections
  styles/          Global and app-level CSS
  App.jsx          Page composition
  main.jsx         React entry point
```

## Edit Your Content

Start with `src/data/portfolio.js`. Update your name, email, skills,
social links, and project details there first.

## Run Locally

```bash
npm run dev
```

## Build

```bash
npm run build
```
